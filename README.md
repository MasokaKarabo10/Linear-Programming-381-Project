# LPR381 Project — Linear & Integer Programming Solver

.NET Framework console application (`solve.exe`) that solves LP/IP models
and performs sensitivity analysis.

## Group Roles
- Member 1 — Core (parser, canonical form, output, menu)
- Member 2 — Primal & Revised Simplex
- Member 3 — Branch & Bound (Simplex + Knapsack)  ← me
- Member 4 — Cutting Plane + Duality
- Member 5 — Sensitivity Analysis + Video

## How to Run
1. Open `src/LPR381.Solver/LPR381.Solver.sln` in Visual Studio 2022.
2. Build (Ctrl+Shift+B).
3. Run — the console menu will prompt for an input file path.
